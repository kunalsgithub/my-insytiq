# INSYTIQ.AI

Web app for **INSYTIQ** — Instagram trend tracking, analytics, and growth tools for creators and marketers.

**Live site:** [insytiq.ai](https://insytiq.ai/)

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Stack

React (Vite), TypeScript, Tailwind CSS, Firebase (Auth, Firestore, Functions).

## Environment

Configure Firebase and API keys per your deployment (see project docs in the repo root).
